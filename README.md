\# **AquaDurán** — Plataforma Colaborativa de Monitoreo de Agua



Propuesta tecnológica conceptual orientada a mitigar la incertidumbre sobre la falta de suministro de agua potable y la gestión de tanqueros en el cantón Durán (Guayas, Ecuador).
